# @gearbox/database

Shared Supabase clients and SQL migrations for the Gearbox monorepo.

## Exports

- `@gearbox/database` — all clients
- `@gearbox/database/client` — browser anon client
- `@gearbox/database/server` — server anon client (RLS)
- `@gearbox/database/admin` — service role (server only)

## Migrations

Run in order from `supabase/migrations/` against your Supabase project.
